作成：2026-11-24．宛先：設計を担当するClaude Code．
位置づけ：本書が正本である．v1仕様書（`plate_70x150_jig_spec_and_instructions.md`）を置き換える．v1仕様書のうち本書に書いていない事項は採用しない．v1の試作SCADは参考扱いで，流用しない（§12）．

## 0．v1からの変更点（要約）

| 項目 | v1 | v2 |
|---|---|---|
| 位置決めの原理 | −X基準壁への突き当て＋両側壁によるセンタリング（すきま片側0.5mm） | 3点固定．左上の基準角に向けて，右下の角から押し付ける |
| 幅方向の再現性 | すきま分の±0.5mmばらつく | すきまに依存しない（プレート縁の精度で決まる） |
| バネ | +X端に1組 | 右下の角に1部品（2本腕）．1本は右辺を−Xへ，1本は下辺を+Yへ押す |
| 爪 | 四隅に必須 | オプション（初期値オフ）．使う場合も−X側の2隅のみ |
| 側壁 | 位置決め面 | ガイドのみ（すきま1mm） |
| バネの造形 | 「寝かせて」と「厚さ方向を積層方向にしない」が矛盾 | 使用時の姿勢のまま造形（§7） |

変更の理由：

- 両側壁で挟む方式は，入れるためのすきま（片側0.5mm）の分だけ毎回位置がばらつく．撮影範囲約200mmを1920画素で撮ると0.5mmは約5画素で，着脱前後の画像比較で目に見える．3点固定ではプレートは毎回同じ3点に押し当てられる．
- 押し方はユーザー案の「右下から左上の基準角へ対角に押す」を採る．ただし1本の板バネを斜めに当てる形は採らない．検討の結果，(1) L字の片持ちバネは方向によって硬さが大きく違い，印刷誤差±0.2mmで押す向きが16〜82度まで振れる，(2) 向きを安定させる長い折り返し形は，右下の角の空き（右11mm，下14mm）に収まらない（ベース長さ182mm以上が要る），ことが分かった．そこで1つのバネ部品に2本の腕を持たせ，各腕がプレートの辺に垂直に当たる形にした．力の向きはプレートの辺で決まり，印刷誤差に左右されない．2本の合力が左上を向く．

## 1．目的

XD4撮影実験において，70×150mmのプレート（試験片）を撮影フレーム内の決まった位置に再現性よく置くための固定治具を，FDM 3Dプリント部品として設計する．着脱を繰り返してもプレートの位置が変わらないことが目的であり，強く締め付けることは目的ではない．

## 2．用語

- 当たり（ダタム）：プレートの縁が接して位置を決める小さな突起．本体と一体．3個ある．
- 基準角：当たりが集まる角．上から見て左上（−X・+Y）．
- ガイド壁：ポケットの周囲の壁．プレートを大まかに導くだけで，位置決めには使わない．
- 角バネ：右下（+X・−Y）の角にねじで留める別部品（PETG）．X腕とY腕の2本の板バネを持つ．
- プリロード：プレートを置いた状態でバネが既にたわんでいる量．
- 爪：プレートの角の上に小さくかかり，浮き上がりだけを止める部分（オプション）．
- 評価領域：撮影して評価するプレート表面の範囲．爪などがかかってはいけない範囲．

## 3．確定事項（ユーザーが決定済み）

1. 対応プレートは70×150mmの1サイズ専用．可変機構は使わない．既存のセンタリングクリップ（対応幅10〜40mm）は流用も拡張もしない．
2. 位置決めは3点固定とする．長辺（+Y縁）に当たり2点，短辺（−X縁）に当たり1点．
3. 押し付けは右下の角から左上の基準角へ向ける．バネは右下の角に1部品．
4. バネは本体と別部品とし，材料はPETG．へたり・破損時にバネだけ交換できること．
5. 本体の材料はPLAまたはPETG（寸法安定性優先）．
6. 磁石は使わない．

## 4．未確認事項と仮定値

次の値は未確認である．**決め打ちせず，すべてパラメータ化し，仮定値であることを成果物READMEの先頭に明記すること．** 実測値が判明したらパラメータ変更だけで対応できること．

| プレートと床・当たりの摩擦係数 μ | 0.3 | バネ力の下限 |

## 5．機能要件

1. プレートを置いて手を離すだけで，角バネが当たり3点へ押し当てて位置が決まる．
2. 着脱を10回繰り返したとき，撮影画像上のプレート縁の位置のばらつきが±0.1mm（約1画素）以内であることを目標とする．
3. プレートを反らせる力，傷つける力をかけない．各腕の押し付け力は0.7〜1.5N．プレートの角（頂点）には当てない．
4. プレートの表裏・向き（180度回転）の間違いに気づける目印がある．
5. 撮影光を遮る高い壁を作らない．プレート上面より上に出る部分は，ガイド壁・当たり・角バネとも3mm以下（ねじ頭を除く）．
6. サポート材なしで造形できる．

## 6．構造仕様

座標系：原点は，プレートが当たりに押し当てられた状態でのプレート中心（＝カメラ中心線を合わせる点）．X＝長辺（150mm）方向，Y＝短辺（70mm）方向，Z＝上向き，z=0はベース下面．上から見て+Xが右，+Yが上．単位はmm．

### 6.1 ベースとポケット

- ベース外形：base_l×base_w＝174×100（パラメータ），厚さbase_t＝4，原点中心．
- ポケット：プレート外形＋片側guide_clearance（初期値1.0）．深さ＝plate_t．プレート上面がベース上面と面一になる．底面は全面でプレートを支える．
- ポケットの四隅に角逃げ（直径2mm程度）を付け，プレートの角やバリが隅に当たらないようにする．
- 角バネの取付部と腕が動く範囲は，ポケットと同じ深さの凹み（取付凹み・腕の溝）とする．取付凹みは角バネの取付ブロックがすきま0.15で入る形にし，交換しても角バネの位置が変わらないようにする．
- ベースの最小寸法：+X側は角バネのX腕とそのたわみ，−Y側は取付ブロックとY腕のたわみで決まり，初期配置では174×100が最小となる．小さくする必要が出た場合は腕の長さ・配置の見直しとしてユーザーに相談する．

### 6.2 当たり（3点）

- 長辺側の当たり2個：+Y側のガイド壁に設け，x＝±datum_span/2（初期値datum_span＝100）．
- 短辺側の当たり1個：−X側のガイド壁に設け，y＝datum_x_y（初期値+28．基準角寄り）．押す力の作用線との関係で，3点すべてに正の押し付け力がかかる位置にする（§6.4の計算）．
- 形状：鉛直な円柱（半径datum_r，初期値2）．先端がプレートの公称の縁位置に来るよう，壁からguide_clearanceだけ突き出す．
- 高さ：ポケット底からガイド壁の上面まで．plate_tを0.8〜2.0に変えても，プレート縁の全厚が当たりに接すること．

### 6.3 ガイド壁

- −X，+Y，−Yの3辺に置く．+X端は出し入れ側で壁を置かない．−Y側の壁は，角バネのY腕の溝の手前で終える．
- 高さはベース上面からguide_h＝3（初期値）．厚さ3．
- 内側上端に面取り1mmを付け，斜めに入れたプレートを導く．

### 6.4 角バネ（別部品，PETG，1個）

- 構成：右下の角の取付ブロックから2本の片持ち板バネが出る．
  - X腕：取付ブロックから+Y方向へ伸び（ポケットの右外側の帯），先端のパッドがプレートの右辺（+X縁）を−Xへ押す．
  - Y腕：取付ブロックから−X方向へ伸び（ポケットの下外側の帯），先端のパッドがプレートの下辺（−Y縁）を+Yへ押す．
- 各パッドはプレートの辺に面で当たる（プレートの角には当たらない）．力の向きは辺に垂直になる．
- 初期値と計算値（PETG，E＝2.0GPa，2本の腕は同じ寸法）：

| 項目 | 値 |
|---|---|
| 腕の長さ spring_l | 30 |
| 腕の厚さ spring_t | 1.6 |
| 角バネの高さ spring_h | plate_t＋3（初期4）．上面がガイド壁と同じ高さ |
| プリロード spring_preload | 2.8 |
| 入れるときの追加たわみ spring_overtravel | 0.8 |
| バネ定数 k＝3EI/L³（I＝h·t³/12） | 0.303 N/mm |
| 押し付け力（プリロード時，各腕） | 0.85 N |
| 根元の応力（プリロード時） σ＝3E·t·δ/(2L²) | 14.9 MPa |
| 根元の応力（最大たわみ3.6mm時） | 19.2 MPa（上限20MPa） |

- 押し付けの確認：Y腕は，床の摩擦と短辺側の当たりでの摩擦の合計に勝つ必要がある．返しの押し下げで床の摩擦が増え，0.3×（0.8＋2×0.31）＝0.43Nと0.3×0.85＝0.26Nの合計0.69N．0.85Nで余裕は1.2倍と小さい．寄りきらないときは手で左上へ寄せる．X腕も同じ．
- 3点の力：X腕の押す位置y_s≈−9.5，Y腕の押す位置x_s≈+49.5，短辺側の当たりy＝+28のとき，長辺側の当たり2個の力は0.32Nと0.53N，短辺側は0.85N．すべて正で，プレートは3点に当たる．
- 計算値はパラメータから自動で出し（SCADのecho），READMEに表として記す．
- 根元にはR3のフィレットを付ける．取付部に応力が集中する切り欠きを作らない．
- パッドに差し込み用の斜面は付けない．縁が斜面に乗ると押す力が上を向き，プレートが浮いて外れる（試作で発生）．当たり面はパッドの全高にわたって立て，上端の角に0.4mmの面取りだけを付ける．
- 入れ方：プレートの右下の角を先に入れて両パッドの返しの下に差し込み，右下へ押して腕をたわませ（追加たわみ0.8mm以内），左上側を下ろして手を離す．
- 返し：パッド2か所と当たり3点のすべての当たり面を，20°の逆テーパー（上ほどプレート側へ出る）とし，プレートの上の縁に当てる．プレート上面から0.8mm上まで張り出し（0.29mm），その上は鉛直．押す力に下向きの成分（各接点0.31N）を持たせ，プレートを床へ押さえ込む．当たりは逆円錐（プレート上面の高さで半径2）とする．
- 5か所が押さえていれば，硬いプレートはどの角も浮かない．薄くてたわむプレートの場合は，ねじ頭で縁を押さえる穴を追加する．
- 入れるときの追加たわみは，当たりの返しの張り出し＋0.5mm以上とする（左辺と上辺を返しに当てずに下ろすため）．
- 当たり面の下端に0.4mmの45°面取りを付ける．角バネはパッドの下端をベッドに付けて印刷するため，一層目のはみ出しがプレート縁の下に入り込むと，押す力でプレートの角を持ち上げる（試作で発生）．
- 取り付け：M3ねじ2本（M3×6，セルフタップ）で取付ブロックをベースに留める．位置は取付凹みで決まる．ねじは抜け止めで，力はほとんどかからない．

### 6.5 爪（オプション）

- claw_enable（初期値false）．プレートが反っていて浮く場合だけ使う．
- 使う場合は−X側の2隅のみ．かかり代claw_overlap（初期値3，3を超えない），プレート上面とのすきまclaw_gap＝0.5．締め付けない．
- 右側（+X）・下側（−Y）には爪を付けない．出し入れと角バネの動きを妨げるため．

### 6.6 固定ねじ穴（仮仕様）

- hole_enable（初期値true）．φ3.2（M3用）を四隅，縁からhole_inset＝8．
- 穴が取付凹み，腕の溝，ポケット，ガイド壁にかかる場合は，その穴を出さない．初期配置では右下の穴が取付凹みにかかるため3個になる．READMEに記す．

### 6.7 目印と指掛け

- 基準角（左上）の近くのベース上面に目印（三角の刻印）．プレート側にも同じ角に印を付ける運用とする（README）．
- ベース上面に，原点（プレート中心）を通るX・Y方向の刻線（ポケットの外側に短く）．
- 指掛け：プレートを取り出すためのくぼみを+X端の上寄り（角バネと重ならない位置）に設ける．

## 7．材料と造形条件

- 本体：PLAまたはPETG．積層ピッチ0.2mm．ベース下面をベッドに置き，サポートなし．
- 角バネ：PETG．**使用時の姿勢のまま造形する**（下面をベッドに置く）．腕の厚さ方向が水平面内に，高さ方向が積層方向になるので，曲げの応力は層の面内にかかり，層間を引きはがす向きには曲がらない．ウォールは腕の厚さ全体がウォールになる本数（0.4mmノズルで4本以上），充填100％．
- 造形条件はBambu Studio前提とし，READMEに記す．

## 9．検証と受け入れ条件

設計側（Claude Code）で確認すること：

1. 組立表示（プレートを参考表示）で，プレートが当たり3点に接し，角バネのパッドがプレートにプリロード分だけ重なって見える（実物ではその分たわむ）こと．それ以外の干渉がない．
2. 差し込み経路：作業者は+X側から，上から見て最大30度ずれた向きで，かつ先端を下げて傾けた姿勢でプレートを入れる．−X側の端がポケット底に届き，+X側の端と下辺を下ろすと，パッドの斜面で腕が逃げること．（改訂：斜面を廃止したため，右下の角を入れて右下へ押し，腕を追加たわみ0.8mm以内でたわませた状態で，左辺と上辺が当たりの返しから離れて下ろせること．）
3. plate_tを0.8と2.0にした2ケースで再レンダリングし，破綻しない．
4. 角バネの計算値がパラメータ変更に追従すること．

実機側（ユーザーが印刷後に確認．手順をREADMEに書く）：

1. 着脱10回で，プレートが毎回3点の当たりに接している．
2. 同じ10回を撮影し，プレート縁の位置（X方向1か所，Y方向2か所）のばらつきが±0.1mm（約1画素）以内．
3. 押し付けでプレートが浮く，反る，傷つくことがない．
4. 腕を50回着脱相当に曲げても折れや目立つへたりがない．

## 10．禁止事項

- §4の仮定値を，仮定と明記せずに決め打ちすること．
- 磁石による固定．
- プレートを上からねじや爪で締め付ける構造．
- 爪のかかり代を3mmより大きくすること．
- 両側の壁で挟んで幅方向を決める構造に戻すこと（v1方式）．
- プレートの角（頂点）を押す構造．
- センタリングクリップ（10〜40mm対応）の機構の流用．

## 11．進め方

1. 本書への疑問点があれば，実装前に短く提示してユーザーの確認を取る．
2. OpenSCADで実装し，§9の設計側の確認を行い，§8の成果物をそろえる．
3. 仮定値の実測が判明したら，パラメータを更新して再出力する．
