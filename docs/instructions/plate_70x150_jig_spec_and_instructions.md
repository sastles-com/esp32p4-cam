# 70×150プレート撮影用固定治具 仕様書・設計指示書

作成：2026-11-24．改訂：2026-11-24，Claude Codeからの質問5件への回答を§13として追加し，§6.1，§8，§9を補正．
宛先：設計を担当するClaude Code．
位置づけ：本書が正本である．既存の試作 `plate_70x150_jig_v1.scad` は参考扱いとし，本書の要件で新規に設計し直すこと（v1の問題点は§10に挙げる）．v1のファイル自体はリポジトリにはなく，Muse側のゴールフォルダにのみある．§10の記述だけで進めてよい（§13-1）．

## 1．目的

XD4撮影実験において，70×150mmのプレート（試験片）を撮影フレーム内の決まった位置に再現性よく置くための固定治具を，FDM 3Dプリント部品として設計する．着脱を繰り返してもプレートの位置が変わらないことが目的であり，強く締め付けることは目的ではない．

## 2．用語

- 基準壁：プレートの長辺方向の一端を突き当てて位置を決める固定壁．
- 側壁：プレートの短辺方向の両側にある壁．両側壁の中央がプレートの幅中心となり，カメラの中心線と一致させる．
- 板バネ：プレートを基準壁側へ軽く押し付ける弾性部品．本設計では本体と別部品にする．
- プリロード：プレートを置いた状態で板バネが既にたわんでいる量．押し付け力はプリロードとバネ定数で決まる．
- 爪：プレートの角の上に小さくかかり，浮き上がりだけを止める部分．上から締め付けるものではない．
- 評価領域：撮影して評価するプレート表面の範囲．爪などがかかってはいけない範囲．

## 3．確定事項（ユーザーが決定済み）

1. 対応プレートは70×150mmの1サイズ専用とする．可変機構（ラック連動のセンタリングクリップ等）は使わない．既存のセンタリングクリップ（対応幅10〜40mm）とは別物であり，流用も拡張もしない．
2. 板バネは本体と別部品とし，材料はPETGとする．へたり・破損時にバネだけ交換できること．
3. 本体側の材料はPLAまたはPETGとする（寸法安定性優先．バネと一体造形しないのでPLAでもよい）．
4. プレートの位置決めは，幅方向は両側壁によるセンタリング，長辺方向は基準壁への突き当て＋板バネの押し付け，で構成する．

## 4．未確認事項と仮定値

次の値は未確認である．**決め打ちせず，すべてパラメータ化し，仮定値であることを成果物READMEの先頭に明記すること．** 実測値が判明したらパラメータ変更だけで対応できる設計にすること．

| 項目 | 仮定値 | 影響範囲 |
|---|---|---|
| プレート厚さ plate_t | 1.0mm（0.8〜1mm級の仮定） | ポケット深さ，爪の高さ，バネの当たり高さ |
| プレート材質 | 未確認．磁石は使わない（鋼板とは限らないため） | 固定方式全般 |
| フレーム内側の床寸法 | ベース外形174×100mmが収まる仮定 | ベース外形のみ．最小約169×89mmまで縮小可能とする |
| 評価領域の端余白 | 爪のかかり代3mmまで許容と仮定 | 爪のかかり代（パラメータ化する） |

## 5．機能要件

1. プレートを置く，横から軽く押す（または自然に），の少ない動作でセットが完了する．
2. 着脱を10回繰り返しても，プレート位置の再現性が目視および撮影画像で問題にならない（検証手順は§9）．
3. プレートを反らせる力，傷つける力をかけない．押し付け力の目標は合計1〜3N．
4. プレートの表裏・向き（180度回転）を間違えて置けない，または間違いに気づける目印がある．
5. 撮影光を遮る高い壁を作らない．壁・爪はプレート上面から必要最小限の高さに抑える．
6. サポート材なしで造形できる形状とする．

## 6．構造仕様

座標系：原点はベース中心．X＝長辺（150mm）方向，Y＝短辺（70mm）方向，Z＝上向き．単位はmm．

### 6.1 ベースとポケット

- ベース外形：174×100mm（パラメータ．§4の仮定），厚さ4mm．
- ポケット：151×71mm（プレート＋片側0.5mmのクリアランス．クリアランスはパラメータ）．底面は全面でプレートを支える．
- ポケット深さはプレート厚さに合わせ，プレート上面と周囲の関係が厚さ変更で破綻しないこと．
- 固定ねじ穴は仮仕様とする．床はアルミフレーム内側にはめ込まれたMDF板であり（2026-11-04の写真で確認），2020フレームの溝が露出している面ではないので，溝ピッチに合わせる必要はなく，M5に変更する必要もない．穴はMDFへの固定を想定したφ3.2mm（M3用）を四隅，縁から8mmを初期値とし，位置と径はパラメータ化する．固定方法自体が未確定であるため，穴なしで出力できるオプション（hole_enable）も用意すること．

### 6.2 壁

- 基準壁は−X端に置く．側壁は±Yの両側に置く．＋X端はバネ側とし，固定壁は置かない．
- v1では壁の高さをプレート厚さ（1mm）としていたが，薄すぎて造形強度と当たりの確実さに欠ける．壁はベース上面から最低3mmの高さを確保し，ポケットの段差でプレート側面を受ける構造に改めること．ただし§5-5のとおり，影と反射の影響を抑えるため，必要以上に高くしない．

### 6.3 爪

- 四隅に設け，プレートへのかかり代は初期値3mm（パラメータ），爪下面とプレート上面のすきまは0.5mmとし，締め付けない．
- バネ側（＋X端）の爪は，プレートの出し入れ時に干渉しない位置・形状とする．

### 6.4 板バネ（別部品，PETG）

- 第一候補は片持ち板バネとする．＋X端に取り付け，先端がプレート端面を−X方向へ押す．
- 設計目安（PETG，ヤング率約2.0GPaとして）：長さ35mm，幅12mm，厚さ1.5mm，プリロード（たわみ）3mmで，押し付け力約1.4N，根元の最大応力約11MPa．これは目安であり，バネ定数と最大応力を計算して成果物に明記すること．最大応力はPETGの降伏に対して十分な余裕（目安として20MPa以下）を持たせる．
- 幅方向の配置は，中央に幅20mmを1枚，または幅10mmを2枚並べる，のどちらかを選んで理由を記すこと．
- 根元にはR3mm以上のフィレットを付け，応力集中を避ける．取付部に応力が集中する切り欠きを作らない．
- 取り付けは交換可能な方式とする．M3ねじ2本止めを第一候補とし，差し込み式にする場合は抜け止めを設ける．
- プレート端面への当たりは面で当たる形状とし，必要なら先端にTPUパッドを付ける余地を残す．
- 代替案として弓形バネ（v1方式）を採る場合は，一体造形ではなく別部品として成立させること．

### 6.5 その他

- バネ側のポケット縁に指掛けの逃げ（スクープ）を設け，プレートを取り出せること．
- 基準角（基準壁側の一隅）に対応する位置に目印（くぼみ，刻印等）を付け，プレートの向き確認ができること．
- ベース上面に，プレート中心線を示す細い刻印を入れること（カメラ中心との位置合わせ用）．

## 7．材料と造形条件

- 本体：PLAまたはPETG．積層ピッチ0.2mmを基本とする．
- 板バネ：PETG．寝かせて造形し，曲げ方向が層の面内になる向きとする（層間剥離の方向に曲げない）．ウォールを多めに取り，充填は100％とする．バネの厚さ方向が積層方向にならないこと．
- 造形条件はBambu Studio前提で，強度に関わる設定（ウォール数，充填）を成果物READMEに記録する．

## 8．パラメータと成果物

OpenSCADでパラメトリックに設計し，少なくとも次の値をCustomizerパラメータとして変更可能にすること．

- plate_l=150，plate_w=70，plate_t=1.0（仮定値）
- clearance=0.5，base_l=174，base_w=100，base_t=4
- claw_overlap=3，claw_gap=0.5
- spring_l，spring_w，spring_t，spring_preload（バネ諸元）
- hole_d=3.2，hole_inset=8

成果物の置き場所：リポジトリ内 `3dprint/plate_70x150_jig/` とする．OpenSCADは2021.01でレンダリングできる構文に限定すること（2021.01以降の新機能を使わない）．

成果物：

1. OpenSCADソース（本体，バネを別ファイルまたは別モジュールとして出力可能にする）．
2. STL（本体用，バネ用を別ファイルで）．
3. レンダリング画像（全体の斜視，上面，バネ部の拡大）．目視で干渉と形状を確認してから提出する．
4. README．仮定値の一覧（§4），バネの計算値（バネ定数，プリロード時の力，最大応力），寸法表，造形条件，組み立てと使い方を含む．

## 9．検証と受け入れ条件

設計側（Claude Code）で確認すること：

1. レンダリングで，プレート（参考表示）と各部の干渉がない．特にバネ側の爪とプレート着脱経路，バネ先端とポケット縁．
2. プレートの差し込み経路でバネと爪に引っかからない．意味は§13-3のとおりで，作業者はプレートを正確な姿勢では入れないため，上から見て平面内で斜めになった姿勢と，横から見て傾いた姿勢の両方を想定する．
3. パラメータ変更（plate_tを0.8と2.0，base_l/base_wを最小値）の3ケースで再レンダリングし，破綻しない．

実機側（ユーザーが印刷後に確認．設計者は手順をREADMEに書くこと）：

1. 着脱10回でプレートが毎回基準壁と両側壁に当たる．
2. バネの押し付けでプレートが浮く，反る，傷つくことがない．
3. バネを50回着脱相当に曲げても折れ，目立つへたりがない．

## 10．既存v1の問題点（流用しないこと）

- バネが本体と一体造形であり，材料を分離できない（本書§3-2に反する）．
- 壁の高さがプレート厚さ1mmしかなく，造形強度と当たりが不足する．
- 爪モジュールの配置計算に不整合がある疑いがある（座標の組み立てを目視確認していない）．
- バネの力と応力の計算値がどこにも記録されていない．

## 11．禁止事項

- §4の仮定値を，仮定と明記せずに決め打ちすること．
- 磁石による固定を持ち込むこと．
- プレートを上からネジや爪で締め付ける構造にすること．
- 評価領域の仮定を広げて，爪のかかり代を3mmより大きくすること．
- センタリングクリップ（10〜40mm対応）の機構を流用すること．

## 12．進め方

1. まず本書への疑問点と，構造の選択（バネの枚数と配置，壁の構成）を短く提示し，ユーザーの確認を取る．
2. 確認後にOpenSCAD実装とレンダリング検証を行い，§8の成果物をそろえる．
3. 仮定値の実測が判明した項目があれば，その都度パラメータを更新して再出力する．

## 13．補足（2026-11-24，Claude Codeからの質問への回答）

1. **v1のscadの所在．** `plate_70x150_jig_v1.scad` はリポジトリにもDownloadsにもないのが正しい．Muse側のゴールフォルダ（`~/workspace/goals/xd4-plate-photography-fixing-jig/files/`）にのみある．受け渡し漏れであり，申し訳ない．ただし設計は§10の問題点の記述だけで進めてよい．v1の流用は想定していない．
2. **フレームの床．** 2026-11-04の写真で確認できる範囲では，アルミ押出フレームの立方体の底面内側にはめ込まれたMDF板である．2020の溝に合わせる設計は不要で，ねじはM3のままでよい．ただし固定方法は未確定のため，§6.1の補正どおり穴は仮仕様＋パラメータ化＋穴なしオプション付きとする．床の現状が写真時点から変わっている場合は，ユーザーの申告が優先する．
3. **「45度方向から差し込む」の意味．** 表現が曖昧だった．正しくは両方の意味である．作業者はプレートをバネ側から差し入れる際，上から見て平面内で最大30度程度ずれた向きで入れ，かつ横から見て先端を下げた傾いた姿勢で入れることがある．その経路でバネ先端とバネ側の爪に引っかからず，先端が基準壁側のポケット底に届くことを確認する，というのが§9-2の意図である．文字どおりの45度ちょうどを条件にはしない．
4. **成果物の置き場所．** `3dprint/plate_70x150_jig/` でよい．センタリングクリップの前例（`3dprint/` 配下）とも一致する．
5. **OpenSCADのバージョン．** 2021.01でのレンダリング確認を前提とする．成果物のSCADは2021.01で動作する構文に限定し，レンダリング確認はそちらで行ってよい．
